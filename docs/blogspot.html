Pada tugas Latihan Dropdown & Kode Pos JavaScript, saya membuat aplikasi registrasi mata kuliah bernama KRS Studio. Aplikasi ini menghubungkan data mahasiswa, pilihan mata kuliah, dan alamat melalui form interaktif menggunakan HTML, CSS, dan JavaScript.

Fokus latihan adalah autocomplete nama, hubungan antar-dropdown, pencarian kode pos, dan validasi form. Pilihan mata kuliah menyesuaikan program studi dan dosen menyesuaikan kuliah yang dipilih. Data yang telah disimpan dapat dicari, diedit, dan dihapus melalui tabel.

Konsep KRS Studio

Tampilan menggunakan warna teal, latar krem, dan ilustrasi buku. Sebagai tambahan, terdapat ringkasan jumlah registrasi, jumlah mahasiswa berdasarkan NIM, akumulasi SKS, serta pengecekan mata kuliah ganda dan batas SKS.

Checklist Kesesuaian Latihan

  1. Selesai: form nama mahasiswa, NIM, mata kuliah, dan dosen, dengan rekomendasi nama saat mengetik.
  2. Selesai untuk dataset latihan: pencarian kode pos dari provinsi, kabupaten/kota, dan kecamatan, disertai informasi daerah.
  3. Selesai: Latihan JavaScript 1 berupa validasi form registrasi umum dan validasi email.
  4. Selesai: list dropdown dinamis untuk mata kuliah, dosen, dan wilayah.

Detail pemetaan implementasi dan bukti hasil tersedia pada checklist project.

Tujuan Latihan

  • Menyusun form, dropdown <select>, tabel, dan dialog menggunakan HTML semantik.
  • Mengatur layout responsif dengan CSS Grid, Flexbox, dan media query.
  • Menggunakan JavaScript untuk membentuk opsi dropdown berdasarkan pilihan sebelumnya.
  • Menampilkan kode pos otomatis dari struktur objek wilayah.
  • Menerapkan validasi, pengelolaan array, pencarian, dan pagination.

Alur Form Registrasi

  1. Data mahasiswa: pengguna mengetik nama untuk melihat rekomendasi. Pemilihan rekomendasi mengisi nama, NIM, dan prodi; nama baru tetap boleh diisi sendiri.
  2. Mata kuliah dan dosen: dropdown menampilkan kuliah dari prodi yang dipilih, kemudian dosen mengikuti mata kuliah. Informasi kode kuliah dan SKS diperbarui.
  3. Alamat: pengguna memilih provinsi, kota, kecamatan, dan kelurahan secara berurutan.
  4. Kode pos: input terisi otomatis berdasarkan kelurahan dan menggunakan atribut readonly.
  5. Simpan: data yang valid dimasukkan ke array lalu ditampilkan pada tabel.

Satu registrasi mewakili satu pilihan mata kuliah. Seorang mahasiswa dapat memiliki beberapa registrasi dengan NIM yang sama, selama mata kuliahnya berbeda dan total SKS tidak melebihi batas simulasi.

Implementasi JavaScript

1. Data dalam Array Objek

Registrasi disimpan pada array registrations. Setiap objek berisi identitas mahasiswa, prodi, mata kuliah, dosen, kelas, dan pilihan wilayah. Aplikasi dimulai dengan delapan registrasi contoh dari tiga mahasiswa fiktif. Nama dosen juga menggunakan data contoh.

Penyimpanan menggunakan memori browser. Perubahan berlaku selama sesi halaman terbuka dan kembali ke data contoh ketika halaman dimuat ulang. Pendekatan ini memudahkan pengamatan perubahan array saat latihan.

2. Autocomplete Nama Mahasiswa

Event input memfilter direktori mahasiswa berdasarkan huruf yang diketik. Contohnya, ketikan “Na” menampilkan “Nadia Putri”. Daftar rekomendasi dapat dipilih dengan mouse, tombol panah, dan Enter. Escape menutup daftar.

const query = $('name').value.trim().toLocaleLowerCase('id');
suggestedStudents = query
  ? KRS_DATA.students.filter((student) =>
      student.name.toLocaleLowerCase('id').includes(query))
  : [];

Input menggunakan pola combobox dengan daftar rekomendasi. Penjelasan atribut dan interaksi keyboard mengacu pada referensi combobox MDN.

3. Dropdown Mata Kuliah dan Dosen

Fungsi updateCourses() mengambil katalog berdasarkan program studi, lalu membentuk opsi baru dengan setOptions(). Ketika prodi berubah, pilihan kuliah sebelumnya dikosongkan agar tidak tersimpan sebagai pilihan yang tidak sesuai.

function updateCourses() {
  const program = $('program').value;
  const courses = KRS_DATA.courses[program] || [];
  setOptions($('course'),
    courses.map((item) =>
      [item.id, `${item.name} (${item.credits} SKS)`]),
    program ? 'Pilih mata kuliah' : 'Pilih prodi terlebih dahulu');
  updateCourseInfo();
  updateLecturers();
}

updateLecturers() membentuk pilihan dosen sesuai mata kuliah. Ketika kuliah atau prodi diganti, dosen yang dipilih sebelumnya dikosongkan agar tetap sesuai.

4. Dropdown Wilayah dan Kode Pos

Dropdown wilayah mengikuti alur provinsi → kota → kecamatan → kelurahan. Pilihan turunan dinonaktifkan sampai induknya terisi. Saat provinsi, kota, atau kecamatan diganti, seluruh pilihan turunannya direset, termasuk kode pos.

Fungsi berikut membaca kode pos melalui objek wilayah bertingkat. Jika salah satu pilihan belum tersedia, nilai yang dikembalikan adalah string kosong.

function getPostalCode(record) {
  return KRS_DATA.regions[record.province]
    ?.[record.city]
    ?.[record.district]
    ?.[record.village] || '';
}

Dataset dibatasi pada dua provinsi, dua kota, empat kecamatan, dan enam kelurahan di Makassar serta Bandung. Pembatasan ini menjaga fokus pada logika dropdown. Referensi setiap kode pos tersedia pada dokumentasi sumber dataset.

5. Submit dan Validasi

Event submit memeriksa kolom wajib, format NIM 6 sampai 15 digit, mata kuliah yang sesuai prodi, dosen yang sesuai kuliah, kelas, dan kelengkapan wilayah. Input yang tidak valid ditandai dengan pesan danger merah dan keterangan pada kolom terkait.

Terdapat dua aturan tambahan: mata kuliah yang sama tidak boleh didaftarkan dua kali untuk NIM yang sama, meskipun kelasnya berbeda, serta total kredit dibatasi maksimal 24 SKS per NIM. Batas ini merupakan aturan simulasi tugas.

6. Fungsi render(), Search, dan Pagination

render() menyelaraskan isi tabel dengan data terkini. Pencarian dilakukan tanpa membedakan huruf besar dan kecil, kemudian hasilnya dibagi menjadi halaman berisi lima atau sepuluh registrasi.

const filtered = filteredRecords();
const totalPages = Math.max(1,
  Math.ceil(filtered.length / pageSize));
currentPage = Math.min(currentPage, totalPages);
const start = (currentPage - 1) * pageSize;

$('registration-rows').replaceChildren(
  ...filtered.slice(start, start + pageSize).map(createRow)
);

Badge menunjukkan jumlah hasil pencarian. Ringkasan di bagian atas menunjukkan seluruh registrasi, jumlah NIM berbeda, dan akumulasi SKS. Setelah pencarian berubah, halaman aktif kembali ke halaman pertama.

7. Edit dan Hapus

Tombol edit mengisi kembali seluruh form, termasuk dropdown yang dibangun berurutan dari induk ke turunan. Simpan perubahan memperbarui objek lama, sedangkan batal edit mengakhiri mode edit tanpa mengubah data.

Tombol hapus membuka dialog konfirmasi. Data hanya dihapus setelah pengguna memilih “Ya, hapus”. Tabel dan pagination diperbarui, termasuk ketika penghapusan membuat halaman terakhir kosong.

Pencarian Kode Pos Indonesia

Selain kode pos otomatis dalam registrasi, terdapat form pencarian tersendiri. Pengguna cukup memilih provinsi, kabupaten/kota, dan kecamatan, lalu menekan “Cari kode pos”. Hasil menampilkan kode pos serta informasi kelurahan, kecamatan, kota, dan provinsi.

Kata kunci tambahan dapat digunakan untuk menyaring nama kelurahan atau kode pos. Contohnya, memilih Panakkukang menampilkan dua kelurahan contoh. Dataset latihan memuat enam kelurahan di Makassar dan Bandung, sehingga belum mencakup seluruh wilayah Indonesia.

Latihan JavaScript 1: Validasi Form dan Email

Mengikuti referensi Latihan JavaScript 1, saya membuat halaman tambahan dengan dua form. Form registrasi umum berisi nama, alamat, email, password, pilihan kursus, nama perguruan tinggi, dan checkbox persetujuan, dilengkapi tombol kirim serta reset.

JavaScript memeriksa kolom wajib, format email melalui checkValidity(), password minimal delapan karakter, dan persetujuan. Form email mandiri menampilkan feedback untuk email kosong, format salah, atau format valid. Prinsip validasi mengacu pada dokumentasi validasi form MDN.

Form ini mempraktikkan validasi di browser. Password tidak ditampilkan dalam hasil atau disimpan, dan data tidak dikirim ke server.

Tampilan dan Responsivitas

Pada desktop, form berada di kiri dan tabel di kanan. Pada layar kecil, keduanya disusun dalam satu kolom. Tabel memiliki area scroll tersendiri agar semua kolom tetap dapat diakses tanpa membuat halaman melebar.

CSS variables menyimpan warna utama dan warna status. Aplikasi menggunakan font sistem serta SVG lokal. Label form, focus state, skip link, dan dukungan prefers-reduced-motion membantu penggunaan melalui keyboard.

Pengujian

Pengujian menggunakan Chrome dalam mode headless melalui Playwright. Seluruh 28 kelompok pemeriksaan lolos, tanpa error JavaScript atau console selama pengujian.

  • Dropdown prodi dan mata kuliah, cascade wilayah, reset pilihan turunan, serta kode pos otomatis.
  • Autocomplete dengan mouse/keyboard, autofill NIM/prodi, dropdown dosen, dan dosen wajib.
  • Pencarian kode pos sampai kecamatan, kata kunci nama/kode pos, dan informasi daerah.
  • Validasi form registrasi umum, checkbox, password, tombol reset, dan validasi email mandiri.
  • Validasi, tambah, edit, batal, hapus dengan konfirmasi, dan pembaruan ringkasan.
  • Pencarian, pagination, hasil kosong, serta penghapusan data terakhir pada sebuah halaman.
  • Pencegahan mata kuliah ganda dan batas SKS, termasuk perhitungan ketika diedit.
  • Input mirip HTML ditampilkan sebagai teks menggunakan textContent.
  • Tampilan pada lebar 375, 768, 812 dalam orientasi landscape, 1024, dan 1440 piksel tanpa overflow halaman.
